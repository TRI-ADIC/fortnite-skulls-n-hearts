# Fortnite: Skulls N' Hearts

## This is the source code and assets for "Fortnite: Skulls N' Hearts", a short visual novel based on the titular game

This project is NOT endorsed or officially associated with Epic Games in any way. They hold the right to take down anything related to "Fortnite: Skulls N' Hearts" as seen fit.

This project is for the sole purpose of challenging my skills in creative writing. As such, this is my first official, open attempt at it!

Why Fortnite? I like the game. I also like the skins.
